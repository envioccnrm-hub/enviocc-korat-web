## 1. สร้างสเปรดชีตแล้วนำเข้าแท็บ

1. สร้างสเปรดชีตเปล่า ตั้งชื่ออะไรก็ได้
2. นำเข้าไฟล์ในโฟลเดอร์นี้ **ทีละไฟล์**:
   **ไฟล์ → นำเข้า → อัปโหลด** → เลือกไฟล์ `.csv`
   → ตำแหน่งนำเข้า: **แทรกแผ่นงานใหม่**
3. ทำครบทั้ง 7 ไฟล์ แล้ว **ลบแท็บ "แผ่น1" ที่ว่างอยู่ทิ้ง**

## 2. แก้ชื่อแท็บให้ตรงเป๊ะ

Google Sheets จะตั้งชื่อแท็บตามชื่อไฟล์ให้เอง แต่**ต้องตรวจว่าตรงกับตารางนี้ทุกตัวอักษร**
เพราะ `Code.gs` เรียกหาด้วยชื่อนี้ตรง ๆ ผิดตัวเดียวคือหาไม่เจอ

| ชื่อแท็บที่ต้องเป็น | ใช้ทำอะไร |
|---|---|
| `Login รายชื่อผู้ใช้งาน` | รายชื่อหน่วยงาน + รหัสเข้าระบบ + สิทธิ์ |
| `Master_Data_Green` | เกณฑ์ประเมิน Green & Clean |
| `Master_Data_Occ` | เกณฑ์ประเมินอาชีวอนามัยฯ |
| `ติดตามงาน Green & Clean Hospital` | รายการส่งงาน Green |
| `ติดตามงาน อาชีวอนามัยและเวชกรรมสิ่งแวดล้อม` | รายการส่งงานอาชีวฯ |
| `ทะเบียนรายชื่อโรงพยาบาล` | ทะเบียนผลการรับรอง |
| `คลังคู่มือเอกสาร` | คลังคู่มือ (ชื่อแท็บนี้ตั้งอิสระได้ ระบบหาเองจากหัวคอลัมน์ `FileUrl`) |

## 3. กรอกข้อมูลจริง

- **`Login รายชื่อผู้ใช้งาน`** — แถวตัวอย่าง 4 แถวในไฟล์ **ต้องลบทิ้ง** แล้วใส่ของจริง
  - คอลัมน์เรียงตามลำดับ **ห้ามสลับ ห้ามแทรกคอลัมน์**:
    อำเภอ | ประเภทหน่วยงาน | ชื่อหน่วยงาน | รหัส | สิทธิ์ | ชื่อผู้บันทึก
  - ช่อง **สิทธิ์** ใส่ได้แค่ `Admin` (สสจ.) หรือ `Hospital` (โรงพยาบาล)
  - ช่อง **ประเภทหน่วยงาน** ต้องใช้คำที่ระบบรู้จัก:
    `สสจ.` `รพ.ศูนย์` `รพ.ทั่วไป` `รพ.ชุมชน` `รพ.สต.` `รพ.นอก สป.สธ.` `อปท.`
  - ช่อง **รหัส** = รหัสโรงพยาบาล 5 หลัก ใช้เป็นรหัสผ่านเข้าระบบด้วย
  - ⚠️ ต้องมีอย่างน้อย **1 แถวที่เป็น `Admin`** ไม่งั้นจะไม่มีใครเข้าหน้า สสจ. ได้
- **`Master_Data_Green` / `Master_Data_Occ`** — ลบแถวตัวอย่างแล้วใส่เกณฑ์จริง
  ช่อง "หมวด" เว้นว่างได้ ระบบจะยึดหมวดล่าสุดที่เจอ (ใช้กับเซลล์ผสาน)
- **ชีตติดตามงาน 2 แท็บ** — มีแค่หัวคอลัมน์ ไม่ต้องกรอก ระบบเขียนเองเวลา รพ. ส่งงาน
  **ห้ามแก้คำในหัวคอลัมน์** เพราะ `Code.gs` หาคอลัมน์จากคำเหล่านี้
- **`ทะเบียนรายชื่อโรงพยาบาล` / `คลังคู่มือเอกสาร`** — ลบแถวตัวอย่าง แล้วใส่ของจริง

## 4. ติดตั้ง Apps Script

1. ในสเปรดชีตนั้น → **ส่วนขยาย → Apps Script**
2. ลบโค้ดตัวอย่างทิ้ง วางเนื้อหาไฟล์ `Code.gs` ของโปรเจกต์นี้ลงไปทั้งหมด → บันทึก
3. เลือกฟังก์ชัน **`runSelfTest`** → เรียกใช้ → อนุญาตสิทธิ์ → ดูผลในบันทึก
   **ต้องผ่านทุกข้อ** โดยเฉพาะ "สูตรแปลงรหัสหน่วยงานตรงกับหน้าเว็บ"
4. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้ใหม่ → เว็บแอป**
   - ทำงานในชื่อ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
5. คัดลอก URL ที่ลงท้าย `/exec`

## 5. ต่อเข้าหน้าเว็บ

เอา URL จากข้อ 4.5 มาวางทับ `API_URL` ใน `assets/config.js` แล้ว `./bump.sh` → commit → push

## เรื่องที่ยังค้างอยู่ ต้องตามเก็บ

โฟลเดอร์ Drive เดิมอยู่ในบัญชีที่ถูกปิด ลิงก์พวกนี้จะกดไม่ได้ ต้องหาไฟล์มาวางใหม่แล้วเปลี่ยน URL:

| ที่ไหน | ลิงก์อะไร |
|---|---|
| `assets/config.js` → `ADMIN_MANUAL_URL` | คู่มือสำหรับ สสจ. |
| `hospital.html` (3 จุด) | ปุ่ม Download / View ของคู่มือหน้าโรงพยาบาล |

ส่วนโฟลเดอร์เก็บไฟล์ที่ รพ. อัปโหลด — **ล้าง ID ใน `Code.gs` ให้แล้ว**
ระบบจะสร้างโฟลเดอร์ใหม่ให้เองอัตโนมัติในบัญชีใหม่ ไม่ต้องทำอะไร
